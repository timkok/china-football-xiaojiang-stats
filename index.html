FAQ

统计口径摘要

“U17 亚洲杯相关入选/出场球员”如何定义？

本版不使用“主力”表述。该指标仅统计 selections.json 中事件名称包含“U17亚洲杯”且球员为 confirmed 的记录。若未来补充逐场首发、分钟、进球或助攻证据，可在 appearances.json 中单独计算。

集训名单、比赛名单、正式报名、实际出场有什么区别？

集训名单表示进入集训通知；比赛名单或正式报名表示进入赛事报名或参赛名单；实际出场需要 appearance 或 match evidence 支撑。

如何提交纠错？

请补充球员、证据类型、来源 URL、发布时间和需要修改的字段。更新后需运行 npm run validate:data。
